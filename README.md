# Luxe Interiors

Premium Furniture Showroom Website — handcrafted sofas, beds, dining sets and custom upholstery, based in Nigeria.

Built with **React 18 + TypeScript + Vite + Tailwind CSS 4**, with Vercel Analytics enabled.

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the local dev server |
| `npm run build` | Production build (`dist/`) |
| `npm run preview` | Preview the production build |
| `npm run typecheck` | TypeScript check |

## Deployment

Pushes to `main` trigger an automatic Vercel redeploy. Build command: `npm run build`; output directory: `dist`.
